> 有个想法，先查开源档案。从「GitHub 热门仓库聚合」升级为「输入想法 → 匹配开源项目 → AI 深读 → 横向对比 → 决策沉淀」的一站式选型平台。

- **需求匹配**：自然语言 → 需求结构化（硬条件 / 软偏好 / 排除项）→ MySQL 硬过滤 → Qdrant 向量召回 → LLM 重排，契合度按语义、硬条件、活跃度、许可证四项分解，可解释而不是一个魔法分
- **AI 深读**：README 与关键 manifest 抓取清洗、按标题分块入索引，回答基于段落证据，证据不足直接标注「信息不足」
- **逐格对比**：8 个固定维度（定位 / 技术栈 / 部署 / 能力覆盖 / 许可 / 活跃度 / 扩展性 / 风险）生成对比矩阵，支持证据抽屉、Markdown 导出与只读分享
- **工程实践**：SSE 流式输出、GitHub OAuth、每日配额原子扣减、成本看板与 P95 告警；全链路 `X-Request-Id` 追踪，2 核 2G 容器可稳定承载约 35 rps
